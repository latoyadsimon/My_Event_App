Event Planner App: Phase 1 User Journeys + Wireframes

Running example: the Rivera wedding, Sat Jun 12, 2027 · 120 guests · photo booth, karaoke, honeymoon fund. Source: app_outline/user_journeys.md · Walkthrough log: wireframes/walkthrough_rivera.md

Lo-fi on purpose! Boxes + labels. No colors or fonts yet. That's the style guide's job.
Every screen shows:
  • info
  • actions/buttons
  • navigation
  • empty/error state
Every screen is drawn 3 ways: Desktop · Tablet · Phone. The role's main device is drawn first and in bold.
How to read:
  • Blue box = a step
  • Red diamond = edge case
  • Dashed box in a screen = empty/error/edge state
  • Blue note = → System (a backend job to build)
  • ✉ 💬 🔔 rows = an email, text or push that links two screens
Under each title: ⬅ Arrives from and ➡ Next. That's the click path. If either one were blank, it would be a dead end.
Links and buttons inside a screen are pictures, not real links. Follow ⬅ Arrives from / ➡ Next to move between screens. More (n) ▾ = tabs that don't fit on that device.
